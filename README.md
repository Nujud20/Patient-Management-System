# Patient Management System

## Overview
An academic team project that demonstrates the use of data structures to manage patient waiting lists in a clinic.

The system follows a first-come, first-served approach while allowing urgent patients to receive higher priority.

## Main Features
- Add a patient to the waiting list
- Prioritize a patient
- Attend the next patient
- View the waiting list
- Maintain patient history
- Increase waiting priorities over time
- Reorder patients based on priority

## Data Structures and Concepts
- Linked Lists
- Queue management
- Priority-based ordering
- Patient history management

## Main Components
- **Patient Class:** Stores patient information, priority, and waiting time.
- **ClinicSystem Class:** Manages waiting patients and patient history.
- **Main Method:** Provides a menu for interacting with the system.

## Project Type
Academic Team Project
